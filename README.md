# 🎢 Montanha Russa

Projeto desenvolvido em Python para praticar lógica de programação.

## Funcionalidades

- Verifica a altura do usuário
- Calcula o preço do ingresso conforme a idade
- Adiciona taxa para foto de recordação
- Utiliza estruturas condicionais `if`, `elif` e `else`

## Tecnologias

- Python
- diagrams.net para o fluxograma
